## 0. 세 줄 요약

1. **평년(Historical)과 예측이 서로 다른 기상 자료를 쓰고 있었다.** 평년은
   단일 관측소(918430)로 돌려 FDC 임계를 만드는데, 예측 base 는 검보정용
   다지점(4개소) 연결을 그대로 써서 **1.8~2.3배 젖은 상태**에서 출발했다.
2. 둘째로 **관측 공백 처리**가 달랐다 — 918430 은 1982~2024 중 631일이 비어
   있는데, 예측은 메우고 평년은 두었다.
3. 둘을 맞추자 검증이 **4/9 → 9/9** 로 올라갔다. 모형·기후예측·상세화·
   검보정에는 문제가 없었다.

## 1. 발단 — 사용자 지적

테스트 3기간(다우 2021_JJA · 평년 2016_JJA · 과우 2017_JJA)의 결과가 이상했다.

> "Avana의 경우 다우(2021)년은 모두 Normal로 나오는데, 과우(2017)의 경우는
> 비가 적게 온 해로 선정되었는데 다우년과 유사하게 Normal로 분류되어 예측이
> 모두 높게 나온 것 같고, 반대로 평년(2016)의 경우에는 Crisis, Watch, Watch로
> 예측되어 마치 가뭄해인 것처럼 결과가 나왔어."

예측 평균이 **2016(0.0005) < 2021(0.022) < 2017(0.028)** 로, 실제 강수 순위와
뒤집혀 있었다.

## 2. 조사 — 가설을 하나씩 소거

### 2-1. 기후예측(PICASO)에 신호가 있는가 → **있다**

처음에 "앙상블 평균 강수가 세 해 모두 239~300mm 로 평년 수준" 이라며 신호가
없다고 판단했으나, **이는 잘못된 근거**였다. 평균은 분포 꼬리에 끌려 tercile
신호를 가린다. PICASO 원본을 직접 보면 신호가 뚜렷하다.

| 기간 | 6월 AN/NN/BN | 7월 | 8월 | 계절 순신호 | 적중 |
|---|---|---|---|---|---|
| 2021_JJA | 46/33/21 | 9/27/**64** | 23/38/39 | −46 (건조) | 1/3 |
| 2016_JJA | 14/29/**57** | **81**/16/3 | 43/37/20 | +58 (습윤) | 2/3 |
| 2017_JJA | 40/34/26 | 24/38/**38** | **59**/30/11 | +48 (습윤) | 2/3 |

9건 중 5건 적중. **PICASO 는 2021을 건조, 2016·2017을 습윤으로 예측**했고,
유량 예측 순서는 그 예측과 정확히 일치했다. 관측 기준 라벨(다우/평년/과우)과
어긋난 것은 PICASO 가 그 세 해를 거꾸로 본 탓이지 시스템 결함이 아니다.

### 2-2. 상세화(acidwg)가 신호를 깎는가 → **아니다**

처음 측정에서 "BN 확률이 최대 21%p 깎인다"고 보고했으나 **측정 오류**였다.
acidwg 는 범주 경계를 ① 관측 시작연도 `syear: 1985` ② **결측일이 있는 달은
통째로 제외** ③ 관측소별로 산정한다. 같은 기준(`_build_obs_monthly_pool`)으로
다시 재니:

```
9개 경우 최대오차 평균 1.6%p · 최대 3.9%p · 5%p 이내 9/9
```

문서가 보장한 "<5%p" 를 지키고 있다.

### 2-3. 검보정·`calibrated/` 마스터가 손상됐는가 → **아니다**

`default/` + `parameter_changes.csv`(14건)를 적용해 재실행하니 검보정
`top1_sim_daily.csv` 와 **소수점까지 일치**(2,192일 평균 0.12180 = 0.12180).
`calibrated/` 입력파일 120개도 재현본과 **완전 동일**.

### 2-4. 모형 수준 편향인가 → **비교 대상이 틀렸다**

"모의/관측 = 0.16~0.27" 로 모형이 유량을 적게 낸다고 보고했으나, 사용자 지적대로
**검보정 유량·실측 유량은 평가 기준이 아니다.**

> "검보정은 SWAT+ 파라메터 결정을 위해서만 필요한 절차야. … 실제 관측이 없는
> 다른 소유역에도 적용하기 위해서는 분명 Historical 기간에 대해 SWAT+ 모델링
> 결과를 이용했어야 해."

운영 기준은 **단일 관측소 Historical 모의값**이다. 대시보드의 검은 `Observed`
선이 바로 그것이고(실측 유량이 아니다), 평년선·FDC 임계도 같은 자료에서 나온다.

### 2-5. 지하수 파라미터가 패턴 전달을 막는가 → **아니다**

warm-up·파라미터를 고정하고 기후예측만 교체하는 통제실험을 했다
(host 연도 2017 고정, PICASO 확률만 3종 교체):

| 기후예측 | host 2016 | host 2017 | host 2021 |
|---|---|---|---|
| 2021 확률(건조) | 0.01796 | 0.02177 | 0.02023 |
| 2016 확률(습윤) | 0.02480 | 0.03311 | 0.02993 |
| 2017 확률(습윤) | 0.02294 | 0.02784 | 0.02646 |

**어느 유역 상태에서도 순서가 동일**하다. 기후예측 → 유량 전달은 정상이다.
극단 확률로는 **100%AN / 100%BN = 4.99배** 까지 벌어진다(실제 자연변동 4.79배와
같은 수준) — "tercile 예보라 1.5배가 한계" 라던 설명도 틀렸다.

## 3. 진짜 원인 — 기준과 예측의 기상 불일치

### 3-1. 관측소 구성이 달랐다

```
평년 실행 : pcp.cli = 918430 하나, weather-sta.cli 전 지점 → 918430
예측 base : pcp.cli = 4개소,      weather-sta.cli 지점별 서로 다른 관측소
```

warm-up(2013-01~2016-05) 투입 강수 실측:

| 관측소 | 실측 | 918430 대비 |
|---|---|---|
| 918430 (공항) | 2,754 mm | 1.0 |
| 461303 | 6,232 mm | 2.3배 |
| **427608 (산지)** | **9,393 mm** | **3.4배** |
| 461412 | 6,898 mm | 2.5배 |

| warm-up 방식 | 전 유역 투입 강수 | 기준 대비 |
|---|---|---|
| 평년 기준(단일소) | 2,754 mm | 1.0 |
| 기존 era5(다지점) | 4,841 mm | 1.8배 |
| 기존 observed(다지점) | 6,319 mm | 2.3배 |

유출은 강수에 비선형이라(같은 tercile 범주 멤버에서 **13~140배** 차이 관측)
이 차이가 크게 증폭된다. 2016년이 Crisis 로 튄 것도, 2017년이 Normal 로
나온 것도 전부 warm-up 저류 차이였다.

> ERA5 의 지점 편의는 **9%** 에 불과하다(ERA022↔918430 연 계수 0.913).
> 앞서 "1.2~1.8배 과다"라고 한 것은 **관측 결측일을 0으로 합산한 계산 오류**다.
> 또 쿡 관측소들이 7.8km 안에 몰려 있어 ERA5 7격자 매칭은 실제로는 모두
> 같은 격자(ERA022)로 수렴한다 — ERA5 방식은 이미 단일 자료였다.

### 3-2. 관측 공백 처리가 달랐다

918430 은 1982~2024 중 **631일**(2013년 대부분 포함)이 비어 있다.
예측 base 는 그 공백을 메우고, 평년 실행은 두었다. 2016_JJA 는 warm-up 에
공백이 365일이라 이 차이가 가장 크게 나타났다(2021년 7일, 2017년 1일).

## 6. 성능 — TxtInOut 복사 최적화

조사 중 별건으로 확인된 병목. `calibrated/` 에 **이전 실행의 출력물이 남아**
있었다.

```
194개 1.19GB = 출력물 64개 1.18GB(99%) + 입력물 130개 19.5MB
```

멤버마다 TxtInOut 을 통째로 복사하므로 1,000멤버 한 기간에 **1.17TB** 를
복사했다(디스크 190% 포화 → 24워커를 걸어도 SWAT+ 2개만 동시 실행).
출력물은 SWAT+ 가 다시 만들므로 복사할 이유가 없다.

`file_manager.is_swat_output()` 으로 거른 결과(쿡 `default/` 입력 127개 전수
검증, 오판 0건):

```
기간당 14분 → 4분       310기간 전체 72시간 → 21시간
```

## 7. 이번 조사에서 바로잡은 잘못된 진단

| 처음 진단 | 실제 |
|---|---|
| 기후예측에 가뭄 신호가 없다 | 있다(BN 57%, AN 81% 등) — 앙상블 평균으로 본 오류 |
| 상세화가 BN 을 21%p 깎는다 | 정상(1.6%p) — tercile 기준 불일치 |
| `calibrated/` 마스터 손상 | 정상 — 입력 120개 완전 일치 |
| 모형 수준 편향(모의/관측 0.16) | 비교 대상이 틀림 — 검보정은 파라미터용 |
| 4→1 관측소 재배정이 오류 | 의도된 설계(미계측 소유역 대응) |
| ERA5 가 1.2~1.8배 과다 | 9% — 결측일을 0으로 합산한 오류 |
| tercile 예보는 1.5배가 한계 | 5.0배 가능 — 신호 폭이 좁았을 뿐 |

**교훈** — "평가 기준이 무엇인가"를 먼저 확정했어야 했다. 기준을 잘못 잡은 채
증상을 쫓아 여러 차례 엉뚱한 곳을 팠다.
